# STM32 Flappy Bird DotMatrix Game

[![Project Demo Video](https://img.shields.io/badge/Watch-Demo-red)](https://drive.google.com/file/d/19GX24kIL19QxmHylgikVeU4SGZ-weGaX/view?usp=drive_link)

A hardware-level Flappy Bird clone implemented in C using the STM32 HAL library. The game displays gameplay animations on an 8x8 LED matrix utilizing row/column multiplexing, processes input via external interrupts, and triggers game-state sound effects via a buzzer.
